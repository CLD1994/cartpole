# 当前设备的速度指令仿真契约

物理档案与完整边界见 [训练准备](training-readiness.md)。任务为手扶起摆后的平衡，不包含自动起摆。

## 动作与动力学

策略动作 `a∈[-1,1]` 映射 `v_cmd=a×1.25m/s`。动作映射固定，不因质量随机化而改变。执行器使用有加速度限幅的一阶速度参考，再通过有限力伺服驱动仿真关节：

```
dv = clip((v_cmd-v_ref)*physics_dt/(physics_dt+tau), ±acc_max*physics_dt)
v_ref += dv
effort = clip(40*(v_ref-v_actual), ±8N)
```

初始假设：`tau=10–40ms`、`acc_max=8–10m/s²`。8N不是由保持力矩或电流推算出的实测推力；高速力矩衰减、皮带弹性和失步尚未建模。这些假设需要训练后离线核验和真机辨识。

| 参数 | 标称 | 初始随机化 |

| 小车质量，不含摆杆 | 65g，实测 | ±10% |
| 均匀端点摆杆质量 | 231.6g，实测 | ±10% |
| 摆杆长度 | 490mm，实测 | 固定 |
| 转轴到质心 | 245mm，由几何推导 | ±3% |
| 绕质心惯量 | 0.00463393kg·m²，由均匀杆推导 | 按采样质量计算后乘0.85–1.15 |
| 训练位置终止边界 | ±286.6625mm | 固定 |

惯量写入点是质心，不是转轴；仿真通过质心偏移处理平行轴项。初始化仍在轨道中部±150mm、摆角±0.15rad。

## 观测与时间

观测顺序 `[x, θ, ẋ, θ̇]`，单位依次为 m、rad、m/s、rad/s。当前 ONNX 运行器按合同的 `angle_sign` 对角度与角速度使用同一符号映射；接入设备时须用已知方向的运动核验，不能仅凭正负号名称推断，也不能无条件继承旧入口的取反。

初始独立高斯噪声标准差为位置0.05mm、角度1mrad、线速度5mm/s、角速度10mrad/s。它们是初始假设，不等于当前编码器实测噪声。原始 V2 基线未加入速度窗口；Window16 系列提供理想窗口估速，但不模拟固件无效状态。

设备的小车与摆杆编码器均为 MT6835。原始 V2 基线直接读取瞬时关节速度，再加上述噪声；固件则用连续位置在成功采样时间窗口两端的差值除以实际时间差估速。固件的标称窗口为 16ms，提高采样频率到 2kHz 并不会把窗口缩短为 8ms。采样预热、时间间隔异常和过长窗口可能导致速度无效，因此增加高斯噪声不能代替这套观测行为。

观测适配需要按环境分别保存连续位置、采样时间和有效性，并在环境重置时清除对应历史。摆杆角速度须由连续角位置计算，不能对跨越 ±π 的显示角直接求差。状态行没有设备采样时间戳或序号，主机收到数据的时刻不能直接当作采样时刻。Window16 系列已按环境保存连续关节位置并在 reset 后重建窗口，窗口不足时暂用瞬时速度；它不模拟固件采样失败、实际时间抖动或有效性状态机。原始 V2 基线仍使用瞬时速度。

原始 V2 基线为固定500Hz策略、1kHz物理积分；命令延迟6–16ms。Window16-Tau0-Acc9-Hz400 配方使用固定400Hz、2kHz物理积分及9m/s²参考加速度上限；详见 [训练准备](training-readiness.md)。450–500Hz真实策略频率波动尚未实现。奖励/折扣/rollout时间尺度及部署未适配项目见训练准备文档。

## 部署边界

新模型不能交给现有200Hz、0.5m/s动作尺度的部署控制器。当前 [单动作 ONNX 运行器](device/README.md) 已提供 400/500 Hz 调度和对应合同检查，仍需在目标环境核验频率、速度尺度、标定/有效性/故障停机语义。训练参数可用不代表已批准自动运动，也不代表仿真覆盖了所有失步或热保护条件。

## 摆杆场景几何

V2 的视觉圆杆与矩形碰撞体分开，二者端点均位于转轴，长度来自设备档案。小车使用紧凑示意外观，轨道实体全长为1000mm，以金黄色外形表示；标定可用行程853.325mm及运动/终止边界不变；杆宽径和小车外形尺寸均为非实测近似。名义物理属性、随机化范围和独立验证步骤见 [V2 摆杆模型与验证](../../docs/v2-pole-model.md)。

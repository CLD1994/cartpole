# 当前设备的速度指令仿真契约

物理档案与完整边界见 [训练准备](training-readiness.md)。任务为手扶起摆后的平衡，不包含自动起摆。

## 动作与动力学

策略动作 `a∈[-1,1]` 映射 `v_cmd=a×1.25m/s`。动作映射固定，不因质量随机化而改变。执行器使用有加速度限幅的一阶速度参考，再通过有限力伺服驱动仿真关节：

```
dv = clip((v_cmd-v_ref)*physics_dt/(physics_dt+tau), ±acc_max*physics_dt)
v_ref += dv
effort = clip(40*(v_ref-v_actual), ±8N)
```

初始假设：`tau=10–40ms`、`acc_max=8–10m/s²`。8N不是由保持力矩或电流推算出的实测推力；高速力矩衰减、皮带弹性和失步尚未建模。这些假设需要训练后离线核验和真机辨识。

## 物理参数

| 参数 | 标称 | 初始随机化 |
|---|---|---|
| 小车质量，不含摆杆 | 65g，实测 | ±10% |
| 均匀端点摆杆质量 | 231.6g，实测 | ±10% |
| 摆杆长度 | 490mm，实测 | 固定 |
| 转轴到质心 | 245mm，由几何推导 | ±3% |
| 绕质心惯量 | 0.00463393kg·m²，由均匀杆推导 | 按采样质量计算后乘0.85–1.15 |
| 训练位置终止边界 | ±286.6625mm | 固定 |
| 摆角终止边界 | ±60° | 固定 |

惯量写入点是质心，不是转轴；仿真通过质心偏移处理平行轴项。初始化仍在轨道中部±150mm、摆角±0.15rad。

## 观测与时间

观测顺序 `[x, θ, ẋ, θ̇]`。沿用训练与部署角量取反的历史坐标约定，真实设备接入须重新核验，不仅凭正负号名称推断。

初始独立高斯噪声标准差为位置0.05mm、角度1mrad、线速度5mm/s、角速度10mrad/s。它们是初始假设，不等于当前编码器实测噪声。后向速度窗口和无效状态尚未接入仿真。

固定500Hz策略、1kHz物理积分；命令延迟6–16ms。450–500Hz真实策略频率波动尚未实现。奖励/折扣/rollout时间尺度及部署未适配项目见训练准备文档。

## 部署边界

新模型不能交给现有200Hz、0.5m/s动作尺度的部署控制器。部署适配必须同步频率、速度尺度、标定/有效性/故障停机语义，并重新验收。训练参数可用不代表已批准自动运动，也不代表仿真覆盖了所有失步或热保护条件。

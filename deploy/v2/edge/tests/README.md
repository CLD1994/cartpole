# 端侧契约测试

在 `deploy/v2/edge` 运行 `make test PYTHON=/path/to/python`。
Python 环境需安装 `numpy` 和 `onnx`；原生测试需要 C 编译器和 `nm`。
测试不连接开发板。可分别运行 `test-unit`、`test-integration`、`test-dependencies`。

## 测试边界

- 单元测试验证公开的解析、格式化、导出、控制及 cartpole 会话接口。
  设备协作方使用遵循接口契约的替身。控制台解析目标只链接被测解析逻辑，
  丢弃未使用的执行函数，不引入真实串口栈。共享设备替身记录委派参数，
  具体场景设置事件转换及读写结果。
- 集成测试运行真实串口适配器、协议及业务组件，底层使用共享 UART 字节流替身。
  策略生命周期测试运行真实策略分派器及 NPU 适配器，SDK 使用契约替身。
  CLI 测试使用 PTY 验证可执行程序与操作系统串口层交互。
  CPU 和模型包测试使用真实文件及 C 实现；ONNX 导出集成测试将导出权重
  交给真实 C CPU 后端推理，核对输出。
- 依赖检查读取编译器生成的业务模块头文件依赖图，并检查目标文件未解析符号，
  验证业务层没有引用串口或协议实现。这是代码依赖检查，不是运行期模块加载检查。

## 共享辅助代码

`support/` 保存 UART/设备替身、模型夹具、输出格式校验器和 C/Python 枚举桥。
优先复用这些辅助代码，不复制协作方逻辑。替身必须模拟调用方依赖的副作用；
测试所需的调用记录属于替身，不应加入生产业务数据结构。

## 验证限制

这些测试不验证物理电机行为、UART 电气时序、实时调度保证，
也不代替 CV610 板端 NPU 数值及性能测试。

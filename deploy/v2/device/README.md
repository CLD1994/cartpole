# 当前设备的主机会话接口

本目录提供 Python 和 C 的设备会话状态机，以及 Python 只读检查器。它们处理协议、有效性、启动条件和禁用回执，不包含模型推理器，不自动使能、不回零、不回中，也不会替操作者确认左端位置。旧 `../pc_runner.py` 与 `../edge/main.c` 是独立入口，不能直接运行新的 500 Hz 模型。

## 读取设备状态

在仓库根目录运行：

```powershell
python deploy/v2/device/check.py --port COM11 --seconds 2
```

需要 `pyserial`。程序仅发送 `QUERY`、`CALIB?`、`CONFIG?`，不发送 `CONFIG`、`ENABLE`、`CONFIRM LEFT` 或 `VEL`。`preflight_reason=null` 只说明本次接收值满足会话入口条件，不证明设备安全、模型匹配或采样到动作的真实延迟。程序不以退出码代替此字段。串口必须独占；不要同时运行旧控制器或固件维护工具。

设备目标参数来自包内 [设备档案](../../../source/cartpole/cartpole/data/device-profile.json)，Python 不导入 Isaac Lab。控制频率目标500 Hz、速度映射上限1250 mm/s、加速度配置10000 mm/s²。**本目录没有调度器，不能保证500 Hz，也未实现450–500 Hz模型的可变步长。** C 接口接受集成方传入这些值，不能从旧 `edge/config.h` 取默认值。

## 会话合同

Python 使用 `Session(transport, clock, limits)`。串口协作者只实现完整写入或错误；时钟使用单调秒数。C 使用显式时间和发送回调，详见 `edge/session.h`。调用方必须保证写入有界、独占串口，并周期调用超时检查及 `refresh` 查询；状态机不能中断卡死的外部 I/O。

| 阶段 | 条件与行为 |
| --- | --- |
| 观察 | 清空旧预检缓存，只发查询。允许编码器预热后恢复，不发送运动。 |
| 启动 | 调用方显式请求。最近1秒内收到READY/NONE、有效标定、配置读回；最近100ms内收到STATE，最近300ms内收到VEL_VALID 1 1。启动本身不ENABLE也不发VEL。 |
| 活动 | 每次动作前检查数据及1秒内的模式/参数读回；调用方每0.5秒显式刷新查询，过期锁存停止；有限动作[-1,1]乘目标速度得到mm/s。越过由标定长度与软余量派生的边界时封锁向外目标。 |
| 停止 | 停发非零目标，发送VEL0；后续新鲜零速STATE只允许请求DISABLE。只有请求之后的MODE DISABLED NONE才确认禁用。ERR BUSY可重试，但1秒截止不延长。 |
| 结束 | 不允许自动重启。数据恢复不能解除本次失败锁存；必须另建会话并重新查询。 |

完整启动读回包括 `CAL_STATE=2`、`CAL_SAVED=1`、`CAL_STORAGE=0`、100–1000mm范围内的 `CAL_LENGTH_UM`，以及与注入参数匹配的 `VEL_MAX`、`ACC_MAX`、`WDT_MS`、`WDT_DEC`、`X_MARGIN_UM`。默认看门狗策略是100ms与5000mm/s²。检查器不替用户修改不匹配的配置。

`CAL_STATE=3` 表示保存记录存在但本次左参考未确认。操作者应在固件工具中完成实物定位与 `confirm-left`，核对后另行 `enable`。会话接口不能根据当前位置数字证明小车在真实左端。

有效性变为0、STATE或有效性超时、活动期间的固件故障/模式变化、关键回执变化、坏格式状态行和无效动作都会阻止继续发非零目标，并清除缓存。停止过程中继续接收恢复数据仅用于有界停车/禁用确认，不恢复运动。发送失败终止会话；失去通信时无法凭软件确认停车。上层必须检查禁用确认与失败原因，不得用“函数返回了”代替结果。

`Observation.si()`只做单位转换，保留固件坐标符号。模型适配方必须核实导出模型的观测顺序、符号、归一化、动作含义和设备档案，不能未经核实继承旧入口的摆角翻转。训练模型没有在本工作区运行过，不能把会话单测通过当成策略闭环完成。

## 验证与边界

```bash
python -m unittest discover -s deploy/v2/device -p 'test_*.py'
make -C deploy/v2/device/edge test
```

这些单元测试注入发送与时间，通过公开接口验证状态转换，不连接设备。维护者还需在合并后的固件上验证协议组合、目标机串口读写时限、模型推理与控制循环，以及停止/禁用结果。没有在本次工作中运行硬件集成测试。

状态行不含设备采样时间戳或序号，主机接收时刻不等于采样时刻；串口积压不能靠上述接收超时证明已消除。停机读数也不证明机械静止、无打滑或电机实际电流。软边界是最后一层命令限制，不提前规划制动距离。外部推理或接收适配器发现异常时调用公开的 `abort` 接口，锁存停止；不要伪造协议行触发内部处理。本接口不授予高速度试验或无人在场运行的条件。

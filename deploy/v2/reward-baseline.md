# 直立与静止奖励基线

目标是在训练安全行程内保持摆杆直立、小车尽可能静止。稳定位置不必在中心。奖励只是学习目标，不替代固件限位、故障停机或真机验收。

## 奖励定义

策略周期为 0.002 s，RewardManager 将下列每项乘策略周期后相加。位置和速度来自仿真真实关节状态，不是加入观测噪声后的值。`x` 为车位置（m），`θ` 为绕零点包装后的摆角（rad），`v` 为车速（m/s），`ω` 为角速度（rad/s），`a` 为策略原始动作。

| 项 | 乘周期前的表达式 | 作用和限制 |
| --- | --- | --- |
| alive | 未提前终止时 +1 | 鼓励存活；时间上限不属于失败。不能单独证明静止。 |
| terminating | 提前终止时 -5 | 单次失败在 2 ms 下扣 0.01；同时失去后续存活回报。该值保留原有时间缩放，不是扣 5。 |
| pole_pos | -θ² | 唯一目标角为竖直；例如 0.15 rad 时扣 0.0225/s。角度按弧度而非度数计算。 |
| cart_vel | -0.1·\|v\| | 实际速度越小越好，任何安全位置静止均为零；0.06 m/s 扣 0.006/s，0.3 m/s 扣 0.03/s。恢复时同样付出速度成本，权重需联调。 |
| pole_vel | -0.005·\|ω\| | 温和抑制摆杆运动，不取代角度目标。保留当前权重。 |
| cart_boundary | -0.5·[max(\|x\|-0.7L,0)/(0.3L)]² | 内区为零，左右对称，到训练边界 L 时扣 0.5/s，越界后继续增大。不是回中心奖励，不是制动保证。 |
| action_rate | -0.3125·(aₜ-aₜ₋₁)² | 抑制速度请求抖动；不是实际加速度或恒定车速惩罚。保留 200→500 Hz 的平方缩放，适用于平滑动作变化的近似。 |
| success_rate | 0 | 仅记录到时且未提前终止的比例，不参与优化。 |

`L` 从设备软限位内缩 0.13 m 得到，当前约 0.2866625 m。边界奖励从约 0.200664 m 开始，到终止边界还有约 0.086 m。缓冲区中点（约 0.243663 m）扣 0.125/s。它会鼓励离开边缘，但回到内部后不再提供居中激励。可恢复性仍受车速、动作延迟和执行器限制影响。

动作平滑项按时间累积比较：单步 `Δa=0.2` 扣 `0.000025`；车速 `0.06 m/s` 持续 1 s 扣 `0.006`，后者相当于 240 次上述单步变化。平滑分摊动作变化可进一步降低平方成本，但大幅救杆动作仍可能被该项抑制，不能把它当作真实加速度限制。

车速权重 0.1 和 70% 边界起点是可试的工程选择，不是已测得最优值。车速项不过度放大，以免策略为了静止而不救杆；边界项连续且一阶连续，避免跨阈值突然跳奖。未发现这些项有反向奖励或左右符号不一致，但训练效果只能通过新训练和独立评估确认。

## 物理时间与 PPO

`gamma = exp(-dt/2s)`，在 2 ms 下约为 0.9990005，未来 2 s、4 s 的回报权重分别约为 0.368、0.135。2 s 是观察到慢漂移后选取的折中，不表示 2 s 以外不计，也不是安全预测窗口。

`lambda = 0.95**(dt/0.005)` 保持约 0.9796917。GAE 中实际是 `gamma*lambda` 衰减，其 e 折时间约 0.093 s。它控制优势估计的偏差和方差，不等于回报折扣视野。rollout 保持 120 步（0.24 s），长时后果依靠价值网络 bootstrap 传递；增加 gamma 不会自动获得多秒实测轨迹。更长折扣会增加价值学习难度，若训练振荡，后续分别检查 value loss、回合长度和边界失败。

初始条件、物理与动作参数、终止条件、网络、学习率、rollout 和 lambda 均保持不变。奖励与 gamma 共同定义这个基线；此训练结果不能归因于其中某一个改动。后续实验每次只改一个因素。

## 训练与验证边界

从头训练，不 resume 旧模型，并保留独立时间戳目录和参数快照。旧 checkpoint 产生于较早物理配置，不能用它和新模型宣称纯奖励 A/B。比较至少使用相同评估配置、种子、初态范围和回合时长，除成功率外检查边界失败、末态车速与摆角。初速度为零和默认速度随机化应分别报告。

代码审查和静态检查不能证明策略收敛，也不能替代 GPU 上的实际训练。本基线供联调，未做新的仿真运行验证。

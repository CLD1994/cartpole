# 当前设备的训练准备

设备事实的单一记录为 [包内设备档案](../../source/cartpole/cartpole/data/device-profile.json)。训练配置通过 `cartpole.device_profile` 读取它；wheel 也包含档案。`measured` 是操作者确认的物理量与固件报告，`configured` 是请求值，不能当成测得的极限。`unknown` 中空值不作为零进入模型。

## 物理模型

小车运动质量65g（不含摆杆）、摆杆质量231.6g、长度490mm、均匀细杆且转轴在端点，由操作者确认。训练以245mm为质心距，绕质心惯量按 `m L² / 12` 推导，标称0.00463393kg·m²；绕转轴惯量0.01853572kg·m²不重复写入刚体的质心惯量。

随机化以实测值为中心：小车和杆质量±10%、质心距±3%、惯量比例±15%。这些范围是初始建模选择，不是测量误差证明。杆的动态质量、质心与惯量经reset事件覆写；USD可视几何仍为通用资产，不将可视外形当成实物尺寸证据。

标定行程853.325mm与挡块间距900mm分开。固件10mm软余量对应±416.6625mm，训练终止边界再内缩130mm至±286.6625mm。训练终止只结束episode，不能当成真机停车保证。

## 控制与执行器

固定500Hz训练基线：物理积分1ms、每策略步两个子步、策略步2ms。请求速度上限1.25m/s、加速度10m/s²用于模型，训练加速度初始随机化8–10m/s²；它们不是实测持续能力。加速度参数仅限制参考速度变化率，不直接限制物理关节实际加速度。每次reset将参考速度归零，而小车初始实际速度随机为±0.3m/s，因此可能产生初始制动瞬态；此行为保留，需在Isaac目标环境读回验证。跟踪时间常数10–40ms、伺服力上限8N和摩擦范围尚待辨识，不从1.5A配置推断电机实测力矩。

命令延迟随机化3–8策略步，即6–16ms。它表示命令延迟假设，不代替固件速度窗口或观测新鲜度。训练观测当前仍为仿真瞬时速度加噪声，固件后向速度窗口尚未建模。

PPO每次rollout为120步，即240ms；gamma与lambda分别按 `0.99**0.4`、`0.95**0.4` 保持原5ms基准的单位时间衰减。Isaac奖励管理器按步长积分奖励；单次终止惩罚按周期比调整，动作变化惩罚权重另按周期比平方调整，保持对动作变化率的近似时间尺度。旧checkpoint不能因配置更新自动适配，应重新训练。

**尚未实现450–500Hz真实策略节拍波动。** 用户目标允许频率向下10%，对应2.000–2.222ms。当前ManagerBasedRLEnv固定decimation，本基线仅实现500Hz。可变策略周期需要同时处理物理积分、动作保持、episode计时、PPO每步折扣与rollout，不用命令延迟、tau或丢观测冒充该功能。

## 部署边界

500Hz状态流不等于500Hz真机闭环验收。本PR不运行训练、不连接串口、不使能电机。

C与PC部署入口仍需新协议和观测适配，当前控制器保持200Hz，动作映射仍为参考控制器的0.5m/s；**不得直接用它们部署此500Hz/1.25m/s新模型**。旧会话启动仍推送 `VEL_MAX=1000`、`ACC_MAX=5000`、`WDT_DEC=5000`；须在整套部署适配时将前两项同步为1250与10000，而不是只改固件默认；这会改变当前运行配置，不是只读检查，也不修改驱动运行电流。PC `--dry-run` 同样推送这些配置。

C `run` 在READY后会主动回中，旧 `calib` 含自动使能。本仓库尚未接入新标定查询、confirm-left、正常DISABLE以及VEL_VALID的失效锁存。启动应由固件配套工具完成左参考与供电检查；在部署协议适配完成前不得用这些入口直接实机闭环。

## 验证入口

```bash
python -m unittest discover -s source/cartpole/tests -p 'test_*.py'
python deploy/v2/pc_runner_test.py
make -C deploy/v2/edge test
```

CPU单元测试不能代替Isaac Lab/GPU训练启动、动态参数读回、端到端时序及真机闭环验证。

设备档案入口拒绝非法速度、加速度、软余量和质量随机化比例；训练配置另行校验初始化区间完整落在终止边界内，以及加速度随机化上下界有序。修改档案后，不满足任务范围的配置会在启动时明确报错。

# 仿真模型与执行器契约

设备事实的单一记录为 [包内设备档案](../../source/cartpole/cartpole/data/device-profile.json)。训练配置通过 `cartpole.device_profile` 读取它；wheel 也包含档案。`measured` 是操作者确认的物理量与固件报告，`configured` 是请求值，不能当成测得的极限。`unknown` 中空值不作为零进入模型。

## 物理模型

小车运动质量65g（不含摆杆）、摆杆质量231.6g、长度490mm、均匀细杆且转轴在端点，由操作者确认。训练以245mm为质心距，绕质心惯量按 `m L² / 12` 推导，标称0.00463393kg·m²；绕转轴惯量0.01853572kg·m²不重复写入刚体的质心惯量。

V2 每次重置时使用设备档案的 `training` 字段随机化物理参数。小车质量、摆杆质量和质心距使用实测或推导的标称值与相应的 `*_randomization_fraction` 计算对称区间；惯量比例以 1 为中心，再作用于本次抽样质量推导的惯量。小车直线阻尼使用 `cart_damping_range_n_s_per_m`（N·s/m），摆杆转轴阻尼使用 `pole_damping_range_n_m_s_per_rad`（N·m·s/rad）。这些范围是建模假设，不是测量误差或辨识结果。杆的动态质量、质心与惯量经 reset 事件覆写；摆杆几何长490mm且端点与转轴一致；圆杆宽径、小车及轨道外形为示意，不将这些可视尺寸当成实物尺寸证据。

标定行程853.325mm与挡块间距900mm分开。固件10mm软余量对应±416.6625mm，训练终止边界再内缩130mm至±286.6625mm。训练终止只结束episode，不能当成真机停车保证。摆角终止边界为 ±60°；初始化位置在轨道中部 ±150 mm、摆角 ±0.15 rad。任务是手扶起摆后的平衡，不包含自动起摆。

## 动作与动力学

策略动作 `a∈[-1,1]` 映射 `v_cmd=a×1.25m/s`。动作映射固定，不因质量随机化而改变。执行器使用有加速度限幅的一阶速度参考，再通过有限力伺服驱动仿真关节：

```
dv = clip((v_cmd-v_ref)*physics_dt/(physics_dt+tau), ±acc_max*physics_dt)
v_ref += dv
effort = clip(40*(v_ref-v_actual), ±8N)
```

初始假设：`tau=10–40ms`、`acc_max=8–10m/s²`。8N不是由保持力矩或电流推算出的实测推力；高速力矩衰减、皮带弹性和失步尚未建模。这些假设需要训练后离线核验和真机辨识。

## 控制与执行器

固定500Hz训练基线：物理积分1ms、每策略步两个子步、策略步2ms。请求速度上限1.25m/s、加速度10m/s²用于模型，训练加速度初始随机化8–10m/s²；它们不是实测持续能力。加速度参数仅限制参考速度变化率，不直接限制物理关节实际加速度。每次reset将参考速度归零，而小车初始实际速度随机为±0.3m/s，因此可能产生初始制动瞬态；此行为保留，需在Isaac目标环境读回验证。跟踪时间常数10–40ms、伺服力上限8N和摩擦范围尚待辨识，不从1.5A配置推断电机实测力矩。

命令延迟随机化3–8策略步，即6–16ms。它表示命令延迟假设，不代替固件速度窗口或观测新鲜度。原始 V2 基线采用仿真瞬时速度加噪声；Window16 系列已经加入 16 ms 位置差分速度窗口，见下节。

PPO每次rollout为120步，即240ms；gamma与lambda分别按 `0.99**0.4`、`0.95**0.4` 保持原5ms基准的单位时间衰减。Isaac奖励管理器按步长积分奖励；单次终止惩罚按周期比调整，动作变化惩罚权重另按周期比平方调整，保持对动作变化率的近似时间尺度。旧checkpoint不能因配置更新自动适配，应重新训练。

**尚未实现450–500Hz真实策略节拍波动。** 用户目标允许频率向下10%，对应2.000–2.222ms。当前ManagerBasedRLEnv固定decimation，本基线仅实现500Hz。可变策略周期需要同时处理物理积分、动作保持、episode计时、PPO每步折扣与rollout，不用命令延迟、tau或丢观测冒充该功能。

## 观测与时间

观测顺序 `[x, θ, ẋ, θ̇]`，单位依次为 m、rad、m/s、rad/s。当前 ONNX 运行器按台位配置的 `angle_sign` 对角度与角速度使用同一符号映射；接入设备时须用已知方向的运动核验，不能仅凭正负号名称推断，也不能无条件继承旧入口的取反。

初始独立高斯噪声标准差为位置0.05mm、角度1mrad、线速度5mm/s、角速度10mrad/s。它们是初始假设，不等于当前编码器实测噪声。原始 V2 基线未加入速度窗口；Window16 系列提供理想窗口估速，但不模拟固件无效状态。

设备的小车与摆杆编码器均为 MT6835。原始 V2 基线直接读取瞬时关节速度，再加上述噪声；固件则用连续位置在成功采样时间窗口两端的差值除以实际时间差估速。固件的标称窗口为 16ms，提高采样频率到 2kHz 并不会把窗口缩短为 8ms。采样预热、时间间隔异常和过长窗口可能导致速度无效，因此增加高斯噪声不能代替这套观测行为。

观测适配需要按环境分别保存连续位置、采样时间和有效性，并在环境重置时清除对应历史。摆杆角速度须由连续角位置计算，不能对跨越 ±π 的显示角直接求差。状态行没有设备采样时间戳或序号，主机收到数据的时刻不能直接当作采样时刻。Window16 系列已按环境保存连续关节位置并在 reset 后重建窗口，窗口不足时暂用瞬时速度；它不模拟固件采样失败、实际时间抖动或有效性状态机。原始 V2 基线仍使用瞬时速度。

## 可选单动作训练配方

主线同时保留原始 V2 基线与 Window16、Window16-Tau0、Window16-Tau0-Acc9-Hz400 配方。Window16 在控制步采样连续关节位置，以 16 ms 两端差分估速；窗口不足时使用瞬时速度，reset 清除该环境的历史。400 Hz 下 16 ms 不是整数控制步，历史端点使用线性插值。这是理想窗口模型，不模拟 SPI 失败、固件有效性锁存或串口积压。

Tau0 配方移除参考速度一阶滤波，保留加速度限制。Acc9-Hz400 使用 0.5 ms 物理子步、5 个子步一次策略决策，参考加速度上限 9 m/s²，reset 随机化为 8–9 m/s²。该配方继承 Window16-Tau0 的 PPO 和奖励参数，不应声称所有单位时间尺度已重标定。具体任务与命令见 [400 Hz 配方](400hz-acc9.md)。

## 部署边界

500Hz状态流不等于500Hz真机闭环验收。主线代码和离线检查不代替对应版本的目标环境训练与实机验收。

[设备运行器](../../deploy/v2/device/README.md) 已包含单动作 ONNX 推理、固定 400/500 Hz 调度、模型清单核验及可选 STEP_LOSS 事件记录。运行器不会自动设置固件参数、标定或使能；模型清单从训练配置生成，实际标定由设备读取并锁定。独立的旧 C 与 PC 部署入口仍需新协议和观测适配，这些旧控制器保持200Hz，动作映射仍为参考控制器的0.5m/s；**不得直接用它们部署400/500Hz、1.25m/s的新模型**。旧会话启动仍推送 `VEL_MAX=1000`、`ACC_MAX=5000`、`WDT_DEC=5000`；须在整套部署适配时将前两项同步为1250与对应配方的加速度配置，而不是只改固件默认；这会改变当前运行配置，不是只读检查，也不修改驱动运行电流。PC `--dry-run` 同样推送这些配置。

C `run` 在READY后会主动回中，旧 `calib` 含自动使能。这些旧入口尚未接入新标定查询、confirm-left、正常DISABLE以及VEL_VALID的失效锁存。启动应由固件配套工具完成左参考与供电检查；在部署协议适配完成前不得用这些入口直接实机闭环。

## 验证入口

```bash
python -m unittest discover -s source/cartpole/tests -p 'test_*.py'
python deploy/v2/pc_runner_test.py
make -C deploy/v2/edge test
```

CPU单元测试不能代替Isaac Lab/GPU训练启动、动态参数读回、端到端时序及真机闭环验证。

设备档案入口拒绝非法速度、加速度和软余量。物理随机化比例必须为 [0, 1) 内的有限数值，阻尼区间必须是两个有限、非负且有序的端点；两端相等表示固定值。这些字段缺失时拒绝启动，不使用默认值。训练配置另行校验初始化区间完整落在终止边界内，以及加速度随机化上下界有序。修改档案后，不满足任务范围的配置会在启动时明确报错。

# 训练与筛选入口

本流程只负责训练产物，不发送设备命令，也不更改固件参数。

- [训练指标](training-episode-metrics.md)：完整结束回合、失败与部分回合的统计口径。
- [动态候选与冻结策略筛选](../scripts/evaluation/TRAINING_CANDIDATES.md)：默认保留三个候选、默认只评估已保存候选；有界并行后独立 holdout。
- [可选 400 Hz / Acc9 配方](training-400hz-acc9.md)：奖励、折扣、窗口观测、动作延迟的明确差异。

原 V2 任务保持回中奖励与原折扣。Window16 系列采用独立平衡配方。训练、评估与导出必须使用同一任务和配置；文件名不能代替配置核验。

训练指标只用于提名，冻结评估与 holdout 不能替代真机验证。本整合不纳入双动作及其协议。请使用经过单独核验的部署入口，不在训练工作区运行中切换代码。

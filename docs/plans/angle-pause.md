# 摆角暂停设计与执行计划
超过训练摆角范围时不再发送 VEL；默认绝对摆角达到 60° 暂停，回到 58° 内恢复。暂停不主动 DISABLE，不自动 ENABLE，退出、故障和通信失效仍沿用原停车。
非暂停期间先检查原命令期限，不能借新角度遮蔽超时。暂停继续接收、检查 4/12ms 观测期限并刷新元数据。恢复重建命令预算与栅格，重新推理，不复用旧动作。
实际写完成时间保持真实，跨暂停间隔单独标记，不混入正常抖动统计。只读诊断不启用暂停。
实施：先测试纯滞回/预算状态转换，再接主循环和写前最新帧检查，再测试实际会话与刷新协作，最后回归设备测试。仅主机接收新鲜度；无硬实时或设备响应保证。固件看门狗若改变模式仍退出，不绕过故障。

## 状态转换

| 当前状态 | 条件（先核验 MODE、FAULT 与接收错误） | 结果 |
|---|---|---|
| 正常 | 原活动命令硬期限已经到达 | 故障停车，不允许转暂停规避期限 |
| 正常 | 观测有效新鲜且绝对角度 >= 进入阈值 | 暂停，不发速度，继续查询 |
| 正常 | 绝对角度 < 进入阈值 | 保持原过期候选等待、推理与发送流程 |
| 暂停 | 观测年龄达到 4 ms（debug 为 12 ms） | 故障停车 |
| 暂停 | 新鲜观测角度 > 恢复阈值 | 保持暂停，命令间隔期限豁免 |
| 暂停 | 新鲜观测角度 <= 恢复阈值 | 恢复，重建预算与栅格，重新推理 |
| 任意 | MODE 改变、FAULT、坏帧、元数据/接收超时 | 原会话失败路径，不自动恢复 |
| 只读诊断 | 任意有限角度 | 不启用暂停，保留原调度诊断 |

查询不会续固件速度看门狗。暂停后固件按原看门狗减速；本功能不要求恢复时静止。独立的 9 ms 参数仅覆盖命令硬期限，默认、观测、推理及固件看门狗均不变。

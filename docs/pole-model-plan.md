# V2 摆杆模型执行计划

## 行为契约

V2 的摆杆在 `pole` 刚体局部坐标中沿 +Z 延伸，近端位于转轴原点，远端位于设备档案定义的杆长。视觉圆杆与矩形碰撞体分开，二者长度和端点一致。质量、名义质心及横向质心惯量由设备档案推导，回合重置仍应用既有随机化。小车和轨道物理、关节名称、轴向、锚点和 V1 任务不变。旧 checkpoint 保留，但不能视作新模型训练结果。

输入资产缺少预期 pole、几何子树或端点转轴时停止创建，不能默默使用错误模型。杆宽厚尚未实测，沿用示意尺寸，不代表实物碰撞精度。

## 实施与验证

1. 在专用 V2 spawner 中复用 stock USD，克隆前替换杆几何并设置名义物理属性。
2. 使用 OpenUSD 独立检查几何范围、原几何停用、关节不变和属性；不把写入后的应用缓存称作物理读回。
3. 在用户 Isaac Lab 3.0 / PhysX 上核验后端属性和一环境自由摆，再做 64 环境训练冒烟；未运行的验证单独记录。
4. 使用独立分支提交待评审 PR。依赖 PR #5 的 Isaac Lab 3.0 启动兼容，不修改该 PR 工作树。

## 示意外观与物理边界

视觉单独使用无碰撞 API 的圆杆和紧凑车体，杆长由设备档案决定。杆径 8 mm、车体 40×50×24 mm、转轴直径 16 mm 均为方便观察的示意尺寸，不是实测。车体及转轴视觉相对于现有关节锚点放置。原碰撞体只隐藏显示，质量、惯量、关节及训练设置保持不变。实现后检查视觉端点、API 分离以及关节/碰撞属性未改变；云端静态验证不替代现场渲染与 PhysX 验证。

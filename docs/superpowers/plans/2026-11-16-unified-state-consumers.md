# 统一状态帧部署消费者实施计划

**目标：** Python 与 C 部署消费者使用同一帧中的两路有效性及观测，不以缺失值冒充真实值。

**架构：** 在串口行与会话状态机边界解析新格式；模型只有在两路有效且数据新鲜时可获取完整观测。原有接收字节、积压、超时、故障锁存和停车边界不放宽。线格式为 `STATE boot8 tick8 flags1 cartseq4 poleseq4 cartage4 poleage4 x8 theta8 vx8 vth8`，全部定宽十六进制。boot/tick为32位，seq为16位，年龄单位µs，有效上限20000，测量为int32二补码。无效路seq0/ageffff/value0解码为None。

**范围：** deploy/v2/device 的 Python/C 消费者及其测试、部署说明。不修改训练。固件统一使用 ACC_MAX，部署读回不要求独立看门狗减速度字段。

## 行为矩阵

| 输入/状态 | 处理 |
| --- | --- |
| 新格式完整、两路有效且新鲜 | 原子更新模型观测 |
| 任一路无效 | 清除完整观测，活动会话停止 |
| 格式/范围非法、缺字段、旧协议 | 拒绝该帧，不延长观测有效期 |
| 重复采样 | 不刷新对应样本年龄 |
| 重启/倒退 | 活动会话停止，不自动恢复 |
| 超时后收到新帧 | 已停止会话不恢复 |
| 原始字节乱码、超长、积压 | 保留现有接收失败及停车流程 |
